# MinerU output files

## Default output

The default text parsing profile writes only these results under the parse
directory:

```text
{name}.md
{name}_content_list_v2.json
images/                  # created only when images are extracted
```

The Markdown file is the primary result. The JSON file contains the structured
content blocks. Image references in Markdown point to files in `images/`.

`images/` is enabled by default. It is created lazily, so documents without
extractable images do not receive an empty image directory.

## Optional diagnostic outputs

Layout PDFs, span PDFs, model output, middle JSON, and the original PDF are
diagnostic or archival artifacts. They are not generated by the default CLI
profile. Enable them explicitly with the corresponding output flags when
debugging or auditing a parse.

## Structured output

`{name}_content_list_v2.json` is the supported structured output. The former
`{name}_content_list.json` file is not generated and is not read by the current
code.

The exact block schema depends on the selected backend. Consumers should
validate the backend-specific schema before processing the JSON.
